# Следующая предварительная сборка Rust Browser

- Движок Servo обновлён до 0.8.0.
- Сокращены пересчёты страницы при обновлении кадров видео.
- Подключён GStreamer для обычного аудио и видео.
- Менеджер паролей использует системный выбор CSV-файла для импорта и экспорта.
- Сохранены управление музыкой, поиск вкладок и восстановление закрытых вкладок.

Это экспериментальная неподписанная сборка Windows x64. Для запуска распакуй
комплект и открой `Start-Browser.cmd`, сохранив папку `app` целиком.
Методика проверок и состояние экспериментальных API описаны в `TESTING.md`.
